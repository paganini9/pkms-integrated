# T-89 컴포지셔널 프레임 재측정 — Solar vs Claude (authoring 기본 provider 결정 입력)

> 개선 프레임(복합어 분해 + 전체 추출 + few-shot) 적용 후, T-90 의 두 문장을 Solar vs Claude 로 재측정.
> **원칙: 프레임이 먼저**(모델 스위치가 프레임 결함을 덮지 않게). 2026-07-11.

## 재측정 결과

### "고무 블레이드"
| | 프레임 전(Solar) | **프레임 후(Solar)** | Claude |
|---|---|---|---|
| 개념 | `고무 블레이드(PartType)` 원자 | `블레이드(Component)` + `고무(Material)` | `블레이드` + `고무` |
| 관계 | (없음) | `블레이드 —hasMaterial→ 고무` | `블레이드 —hasMaterial→ 고무` |

### "겨울철 저온에서 고무 블레이드는 소음이 발생한다"
| | 프레임 전(Solar) | **프레임 후(Solar)** | Claude |
|---|---|---|---|
| 개념 | `고무 블레이드`·`겨울철 저온` (**소음 누락**) | `겨울철 저온`·`블레이드`·`고무`·`소음` | 동일 4개 |
| 관계 | `고무블레이드 —causes→ 소음` | `hasMaterial`·`causes`·`conditionedOn` 3개 | 동일 3개 |

## 관찰 (측정된 사실)

- **프레임 개선만으로 Solar 가 Claude 와 동일해졌다.** 복합어 분해(`블레이드`+`고무`+`hasMaterial`)·증상 누락 해소(`소음` 추출)·조건부 인과(`conditionedOn`)까지 Solar==Claude.
- **결론: 이 케이스들에선 모델 스위치(Claude) 불필요.** 프레임이 근본이었다("프레임 개선이 먼저" 확인).
- **authoring 기본 provider = Solar(무료) 유지.** Claude 옵션은 프레임으로 못 푸는 더 어려운 케이스의 escalation·비교용으로 남긴다(T-90 A/B).

## 부수 효과 — in-domain 과차단 해소

MVP 검증서에서 관측된 자유질의 과차단이 **프레임 + 어휘층(altLabel)** 으로 해소:
- "겨울에 고무 블레이드를 쓰면 소음이 나나요?" → 추출 `겨울철 저온·블레이드·고무·소음`(전부 어휘층) → 접지 통과 → **답변(출처 S1~S6)**. (이전: "겨울" 변형 → unknown → 차단.)
- **우회 8종 9/9 차단 유지**(어휘층 정확일치·부분일치 금지 — "타이어 고무" 여전히 차단).

## 남은 변동성 (안전)

- solar-pro3 는 여전히 호출별 미세 변동(간헐 particle 부착 "재질은" 등). 어휘층 정확일치라 particle 변형은 unknown → **안전 fail-closed**(환각 아님). OOV 트리아지(다음)가 이런 변형을 매핑 후보로 제시해 흡수.
