## 측정 항목

1. **K1~K5 (M1 지식 저작) 회복** — 문장별 엔드투엔드로 캡처: IRI 민팅(공백 라벨 500 없음)·canonical 타입 판정(블레이드→WiperBlade/PartType, LLM Component 무시)·OOV 승인 편입(한글 altLabel 부착)·파생 규칙(id=`<문장코드>Rule`·about_symptom=온톨로지 증상)·Causation 저장 그래프 기록(0→1)·satisfy 판정 변화. **저장 성공/차단 집계 → ③(1/26) 대비 회복치.**
2. **K2 플래그십 실스택 루프** — 유닛 아닌 배포 스택으로: K2 저작 → Ozone(EnvCondition)·Crack(Symptom) 승인 편입 → `env=Ozone` 설계(CD-15) satisfy → exhibited `[]`→`[Crack]` 확인, R5류 RB(`forbidsSymptom Crack`) 주입 시 `satisfies=false`·`violated=[RB_NoCrack]`.
3. **A/B 마진 재측정** — 같은 K 서브셋 Claude vs Solar 추출 대조(복합어 분해·증상 포착·인과 프레임·저장 성공). ③에서 "마진이 구조결함에 눌려 값을 못 냄" → **구조결함 해소 후 회복 여부**를 표로.
4. **R 서브셋 잔여결함 스코핑** — R1·R5 를 M2/RB 경로에 투입. 여전히 실패하는지 + 어느 결함(A2 RB 증상맵 하드코딩·A4 M1/M2 라우팅)이 **지배적**인지 로그. (회귀 아님 — **2단계 우선순위 자료**.)
5. **불변 확인** — satisfy 시드 회귀 전건 그린(실스택)·도메인 밖(자전거·타이어) fail-closed 유지.
