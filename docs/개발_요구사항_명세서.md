## 1. 개요 / 범위

와이퍼 설계 6문장을 SPMM 확장 온톨로지(RDF/SHACL) 위에 올려, **자연어 지식 입력 → 구조화 → 지식맵 → 설계검증(satisfy) → 환각비교 Q&A**를 지원하는 통합 시스템. 두 기존 구현(pkms-dev-system 프론트·기능, pkms-web RDF 코어)을 하나로 통합한다.

- **MVP 경계**: P1 SC-1~4(입력·satisfy·환각비교·지식맵), P2 SC-6~8(상위 온톨로지·규칙·거버넌스). SC-5(VisualDiff)=P1.
- **도메인**: 와이퍼 단일. **비목표**: 규정 PDF 대량추출·FMEA·파인튜닝(KG-FIT/OntoTune/K-ON)·다중도메인·SMT 비선형 수치.

## 3. 비기능 요구사항 (NFR)

- **성능/지연**: 추출 SSE 첫 응답 목표 < 2s. satisfy·명세검증은 reasoner **시그니처 캐시**로 캐시 후 목표 < 수 초(xpSHACL 초기 ~65s/캐시 후 ~20s 사례 참고 → 서브그래프 한정·캐시 필수).
- **신뢰성**: reasoner·LLM 호출에 Timeout/Budget + Smart Retry + Circuit Breaker(2개↑). 결정론적 검증(SHACL/reasoner)을 LLM보다 우선. Mock 폴백 상시.
- **보안**: API 키는 시스템 환경변수(코드·`.env`·git 금지, 로그 마스킹). 프론트에 백엔드 키 미노출. 시크릿 분리.
- **관측성**: 추출·검증·satisfy에 trace/log. satisfy **justification을 감사 로그**로 보존.
- **이식성**: Docker Compose(React·Node BFF·Python 지식서비스·Oxigraph·벡터). **로컬=Docker 동일 구조**.

## 4. 자율성 · 가드레일

- **자율성 레벨: 제안형(승인 후 반영)**. LLM은 추출·Q&A 초안만 생성.
- **HITL 게이트**: ① 추출→저장, ② 상위 온톨로지 편집 저장, ③ 도메인 규칙·SHACL 변경 저장, ④ satisfy 결과 채택. 각 지점에 승인 액션 필수.
- **입출력 검증**: 입력 Pydantic 스키마 검증. 출력은 추출→OWL/SHACL 게이트 통과분만 저장 가능.
- **면책/안전**: 환각비교에서 LLM 원답변과 검증답변을 시각적으로 구분. "명세 근거 없음"을 억지 답변 대신 명시.

---

## 5. 제약 · 비목표

- **제약**: 와이퍼 단일 도메인. OWL 2 EL + SHACL(EL 밖 표현력은 SHACL로). satisfy 수치는 SHACL+구간 비교기(비선형 SMT 제외). 키는 환경변수.
- **비목표(범위 고정)**: 규정 PDF 대량 자동추출, FMEA 자동생성, 파인튜닝(KG-FIT·OntoTune·K-ON), 다중 도메인 확장, 서버 트리플스토어 운영.

## 6. 가정 · 미해결 질문

- ✅ **해소**: RB 저작(=M2 프로젝트, 자연어 커스텀 빌더) · DesignRule↔SHACL 단일소스(구조화 규칙 컴파일러, 실증) · 문장 중심 저작·프로젝트 지식선택. 상세: [RB-저작-검토.md]·[DesignRule-SHACL-단일소스-검토.md]·[지식-저작-상호작용-검토.md].

2. 카테고리 체계 — 고정 vs 사용자 정의.
3. **임베딩 = 로컬 sentence-transformers 확정**, 기본 **MiniLM 다국어 384**(`paraphrase-multilingual-MiniLM-L12-v2`; 대안 bge-m3 1024·ko-sroberta 768; 무료·오프라인) — AWS×Upstage 프로그램이 임베딩 무료 미포함. chat=Solar-Pro(무료). 설정명 `EMBEDDING_PROVIDER`(mock|local|solar), 개발 기본 mock. **Phase 1 코드에 이미 구현**(`embedder.py` mock|st) → EMBEDDING_MODE→EMBEDDING_PROVIDER 리네임만 반영: [임베딩-로컬-전환-지침.md]. Solar 임베딩은 옵션. (solar-pro3 `json_schema` strict만 2차 확인.) 상세 [Solar-AI백엔드-통합가이드.md].
4. 지식맵 RDF/SPARQL 대량 노드 렌더.
5. SHACL 위반 자연어 설명(xpSHACL식) 범위. RB=증상부재 `owl:complementOf` 정교화(2차).
