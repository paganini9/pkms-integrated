# 공유표준 · 레이어 인터페이스 계약

> 레이어 간 **타입 시그니처**를 고정해 병렬·모의(mock) 개발을 가능케 한다.
> 변경은 `통신_프로토콜.md` Change Control을 따른다. 기준: `기술_설계_명세서.md §3·§5`.
> 버전: v1 (freeze 대상)

## 0. 공통 타입
```python
class Source(TypedDict): title: str; url: str; ref: str; published_at: str|None
class Metric(TypedDict): code: str; value: float; unit: str; source: Source; observed_at: str
class Evidence(TypedDict): id: str; type: Literal["causal","case","news"]; text: str; \
    sectors: list[str]; indicators: list[str]; lead_lag: str|None; lag_window: str|None; source: Source
```

## 1. 데이터 레이어 (02 제공)
```python
class DataCollector(Protocol):
    def collect(self, market_scope: list[str], indicators: list[str]) -> dict[str, Metric]: ...

    def gaps(self) -> list[str]: ...
```

## 2. RAG 레이어 (03 제공)
```python
class Retriever(Protocol):
    def query(self, macro_state: dict, sectors: list[str], k: int = 6,
              weights: dict = {"causal":0.5,"historical":0.5}) -> list[Evidence]: ...
    def is_sufficient(self, hits: list[Evidence], sectors: list[str]) -> bool: ...
    def index_incremental(self) -> int: ...  # _manifest.csv + 내용해시 기준 신규/수정 upsert 수
    def ensure_synced(self) -> None: ...      # 검색 직전 lazy 동기화(증분). query()가 내부 호출
# 적재 트리거: 앱 lifespan 기동 시 index_incremental() 1회 + query() 전 ensure_synced().
# 수집 스케줄은 파일만 쓰고 임베딩 안 함(별 프로세스). 멱등 스크립트 `python -m app.rag.index`로도 실행.
```

class Store(Protocol):

## 4. LLM 레이어 (04 제공)
```python
class LLM(Protocol):
    def generate(self, messages: list[dict], schema: dict | None = None,
                 temperature: float = 0.2, max_tokens: int = 1024) -> dict | str: ...
    # schema 지정 시 structured output(dict), 없으면 자유 텍스트(str)
```

## 6. 모의(mock) 규약
- 각 Protocol마다 `*_mock` 구현 제공(고정 fixture 반환). Phase 1에서 04는 data/rag/store mock으로 그래프 완주.
- mock 산출은 `contracts/mocks/`에 고정 JSON으로 보관(재현성·테스트 공유).
