# 공유표준 · 개발 환경

> 모든 Python 작업(02·03·04·05·08)은 **backend 로컬 venv(Python 3.12)** 또는 **Docker(python:3.12-slim)** 에서 수행한다.
> 호스트 기본 Python 이 3.14 라 의존성 충돌이 나므로 **반드시 3.12 venv 사용**.

## 로컬 venv (권장 — 빠른 개발·테스트)
경로: `macrolens/backend/.venv` (Python 3.12, gitignore 됨).

```powershell
cd macrolens\backend
# venv 생성(최초 1회) — 3.12 인터프리터로
& "C:\Users\jaehyunlee\AppData\Local\Programs\Python\Python312\python.exe" -m venv .venv
.\.venv\Scripts\Activate.ps1          # 활성화 (프롬프트에 (.venv))
python --version                      # Python 3.12.x 확인
pip install -r requirements-dev.txt   # 의존성(개발 포함)
```

실행/검증:
```powershell
uvicorn app.main:app --reload         # http://localhost:8000/api/v1/health
pytest -q                             # 테스트
ruff check .                          # 린트
```

규칙: 새 터미널마다 `Activate.ps1` 로 venv 활성화. `python`/`pip` 는 venv 안에서 3.12. `.venv` 는 커밋 금지(.gitignore).

## Docker (패리티 — 통합·배포)
`docker compose up` → backend(python:3.12-slim)·frontend·chroma. 호스트 Python 무관.
로컬 venv 와 **동일 Python 3.12** 라 동작 일치.

## 의존성 관리
- 런타임: `backend/requirements.txt` / 개발: `backend/requirements-dev.txt`.
- 새 패키지 추가 시 requirements 갱신 + venv·Docker 양쪽 반영. 데이터 레이어 libs 는 02 Agent 가 Phase 1 에서 추가.

## 포트 표준 (MacroLens 전용 82xx — 다른 프로젝트와 충돌 회피)
| 서비스 | 로컬(venv) | Docker(host:container) | 비고 |
|---|---|---|---|
| backend (FastAPI) | 8200 | 8200:8000 | `uvicorn app.main:app --reload --port 8200` |
| frontend (Streamlit) | 8202 | 8202:8501 | `streamlit run app.py --server.port 8202` |
| chroma | — | 8201:8000 | 임베디드 사용 시 host 포트 불필요 |

- 컨테이너 내부 포트는 표준(8000/8501) 유지, **호스트 포트만 82xx**. compose 내부 통신은 `http://backend:8000`(영향 없음).
- 로컬 backend 접속: http://localhost:8200/api/v1/health · http://localhost:8200/docs
- OntologyResearch 등 다른 Docker가 8000을 쓰더라도 MacroLens는 82xx라 공존 가능.
