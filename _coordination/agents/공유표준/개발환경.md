# 공유표준 · 개발 환경

> 모든 Python 작업(02·03·04·08)은 **`knowledge/.venv`(Python 3.12)** 또는 **Docker(python:3.12-slim)** 에서 수행한다.
> 호스트 기본 Python 은 의존성 충돌이 나므로 **호스트 파이썬 직접 사용 금지 — 반드시 3.12 venv**.

## 서비스 구성

| 서비스 | 스택 | 역할 |
|---|---|---|
| `knowledge/` | Python 3.12 · FastAPI | 지식·추론·RAG(Oxigraph·HermiT·pySHACL·Chroma). **내부 전용** |
| `bff/` | Node 20+ · Express · TS | 오케스트레이션·AI Gateway·SSE. **유일한 외부 표면** `/api/v1` |

## 로컬 venv (권장 — 빠른 개발·테스트)
경로: `knowledge/.venv` (Python 3.12, gitignore 됨).

```powershell
cd knowledge
# venv 생성(최초 1회) — 3.12 인터프리터로
& "C:\Users\jaehyunlee\AppData\Local\Programs\Python\Python312\python.exe" -m venv .venv
.\.venv\Scripts\Activate.ps1          # 활성화 (프롬프트에 (.venv))
python --version                      # Python 3.12.x 확인
pip install -r requirements-dev.txt   # 의존성(개발 포함)
# 로컬 임베딩(ST)을 쓸 때만 추가 — 기본은 mock 이라 불필요
pip install -r requirements-ml.txt
```

실행/검증:
```powershell
uvicorn main:app --reload             # http://localhost:8000/health
pytest -q                             # 테스트
ruff check .                          # 린트
```

BFF·프론트(각자 별도 터미널, venv 무관):
```powershell
cd bff;      npm install; npm run dev    # http://localhost:4000
cd frontend; npm install; npm run dev    # http://localhost:5173 (/api → BFF 4000 프록시)
```

규칙: 새 터미널마다 `Activate.ps1` 로 venv 활성화. `python`/`pip` 는 venv 안에서 3.12. `.venv` 는 커밋 금지(.gitignore).

## Docker (패리티 — 통합·배포)
`docker compose up --build` → knowledge(python:3.12-slim + temurin JRE)·bff·frontend. 호스트 Python·Java 무관.
로컬 venv 와 **동일 Python 3.12** 라 동작 일치.

- 경량(기본): mock 임베딩. `docker compose up --build`
- full(로컬 ML·오프라인 기동): `INCLUDE_ML=true EMBEDDING_PROVIDER=local docker compose up --build`
- 키는 이미지에 넣지 않는다 — 호스트 env(`Studio_API_Key`·`ANTHROPIC_API_KEY`)로만 주입.

**Java/HermiT**: 추론기(HermiT)는 JRE 가 필요하지만 knowledge 이미지에 temurin JRE 가 포함돼 **호스트 Java 설치는 불필요**하다.
호스트에서 HermiT 를 직접 실행해야 할 때만: `winget install EclipseAdoptium.Temurin.21.JRE`.
(JRE 없으면 owlrl 폴백 — `/health` 의 `reasoner` 필드로 확인.)

## 포트 표준
| 서비스 | 로컬(venv/npm) | Docker(host:container) | 비고 |
|---|---|---|---|
| knowledge (FastAPI) | 8000 | 8000:8000 | `uvicorn main:app --reload` · 내부 전용 |
| bff (Express) | 4000 | 4000:4000 | `npm run dev` · 외부 표면 `/api/v1` |
| frontend | 5173 (Vite dev) | 8080:80 | dev 는 `/api` → BFF 4000 프록시 |
| chroma | — | — | knowledge 내 임베디드(별도 포트 없음) |

- 프론트는 **BFF 만** 호출한다. 지식서비스(8000)를 프론트에서 직접 부르지 않는다(내부 구조 비노출).
- 헬스: knowledge `http://localhost:8000/health` · BFF `http://localhost:4000/api/v1/health`
- 8000 을 쓰는 다른 Docker(OntologyResearch 등)와는 동시 기동 시 충돌하므로, 한쪽을 내리거나 compose 의 host 포트를 바꾼다.
